🔎 **IndiaMART WebScraping – EDA Pipeline**

Developed a data pipeline to **scrape product data from IndiaMART**, including product names, prices, and supplier details. The raw data was **cleaned and processed using Pandas**, followed by **Exploratory Data Analysis (EDA)** to identify pricing trends and supplier distribution. Final datasets and insights were **exported to CSV/Excel for further analysis and reporting**. 📊💾

**Tech Stack:** Python, BeautifulSoup, Requests, Pandas, NumPy, Matplotlib
